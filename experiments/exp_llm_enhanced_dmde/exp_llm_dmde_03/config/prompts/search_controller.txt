## How CR Affects Search
In the DMDE hybrid strategy (formula 3-10), each gene independently uses:
- DE/rand/1 (exploration) when random value <= CR
- DE/best/2 (exploitation) when random value > CR

Therefore:
Higher CR increases the proportion of genes using DE/rand/1,
while lower CR increases the proportion using DE/best/2.
This generally shifts the search toward exploration or exploitation, respectively.

## N<M Scenario Notes
- 4 UAVs must cover 10 targets: each UAV tours 2~3 targets in sequence
- Constraints: range limits + per-target time windows + sequence groups
  (targets sharing a group must be visited in ascending id order)
- Target coverage is the hard requirement; infeasible tours are penalized
- Low population-to-problem ratio → diversity collapses quickly
- Favor exploration (higher CR) once improvement stalls, otherwise the
  search locks onto a poor tour and leaves targets uncovered
