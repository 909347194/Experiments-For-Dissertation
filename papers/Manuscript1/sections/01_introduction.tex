The main contributions of this work are summarised as follows.

\begin{itemize}
  \item We propose an \llmdmde{} framework that delegates population seeding and
        crossover-rate control to an LLM while leaving the evolutionary
        operators untouched, so it can be plugged into existing DE
        implementations.
  \item We design \popinit{}, in which LLM-generated candidates are repaired to
        feasibility and de-duplicated before injection, preserving the
        feasibility assumption of DMDE.
  \item We design \crctrl{}, in which the LLM is queried at fixed intervals and
        receives explicit feedback on the previously chosen \CR{} together with
        its fitness and diversity consequences, forming a closed decision loop.
  \item We conduct an ablation study across two scenarios and report solution
        quality, convergence speed and computational overhead.
\end{itemize}
