Differential evolution (DE) is widely adopted for multi-UAV cooperative path
planning, yet its performance hinges on two decisions that are usually fixed by
hand: how the initial population is seeded, and how the crossover rate is set
along the search. This paper proposes an LLM-enhanced DE framework that
delegates these two decisions to a large language model (LLM) without changing
the underlying evolutionary operators. The LLM first repairs and injects a small
number of feasible solutions into the initial population, and then re-tunes the
crossover rate at fixed intervals using feedback on fitness improvement and
population diversity. We evaluate the framework on two scenarios -- a balanced
assignment task and a scarce-resource task -- against a vanilla DE baseline and
against its two components in isolation.
